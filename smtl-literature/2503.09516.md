# Search-R1

Identifier: arXiv:2503.09516  
Paper: *Search-R1: Training LLMs to Reason and Leverage Search Engines with Reinforcement Learning*  
Authors: Bowen Jin et al.  
Link: https://arxiv.org/abs/2503.09516  
Related: [[search_more_think_less]]

## Short summary

Search-R1 trains an LLM to generate multiple search queries during multi-turn reasoning. It supports SMTL's setup claim because stronger search interaction and longer tool-augmented trajectories improve QA performance over standard RAG baselines.
