# DeepResearcher

Identifier: arXiv:2504.03160  
Paper: *DeepResearcher: Scaling Deep Research via Reinforcement Learning in Real-world Environments*  
Authors: Yuxiang Zheng et al.  
Link: https://arxiv.org/abs/2504.03160  
Related: [[search_more_think_less]]

## Short summary

DeepResearcher trains web-search agents with end-to-end RL in real web environments instead of a fixed corpus. It supports the claim that longer, real search interaction trajectories can materially improve deep research performance.
